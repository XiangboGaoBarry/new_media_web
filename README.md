# Xiangbo Gao's Personal Website

Personal website built with React and Next.js.

## Quick Start

1. **Environment**: Node.js `v22` + `yarn`
2. **Install**: `yarn install`
3. **Run**: `yarn dev`
4. **Build**: `yarn build && yarn start`

## Key Scripts

- `yarn dev`: Launch dev server (runs type-check + next dev).
- `yarn build`: Production build (runs type-check + next build).
- `yarn update:pubs`: Fetch latest publications from Google Scholar (requires `SERPAPI_KEY` in `.env.local`).
- `yarn clean`: Clean build artifacts (`.next`, `build-tsc`).
